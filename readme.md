# 🛒 E-Commerce Platform

## 📌 About the Project

This project is a **Full Stack E-Commerce application** developed using modern technologies for both frontend and backend development.

The application allows users to browse products, view product details, add items to their shopping cart, and manage their selected products.

The frontend was initially developed using **React.js**, while the backend was built with **Node.js** and **Express.js**, using **MongoDB** as the database.

As part of the payment integration, **Stripe** was used as a payment gateway to demonstrate how online transactions can be processed.

The project is currently being migrated to **Next.js**, with a focus on improving the user interface, enhancing the overall architecture, and implementing **Auth.js (NextAuth.js)** for more robust user authentication and session management.

The long-term goal is to deploy the application online, making it accessible as a fully functional e-commerce platform.

## 🚀 Technologies Used

### Frontend
- **React.js** – Building the user interface.
- **Next.js** – Currently migrating the application to Next.js.
- **React Router DOM** – Managing application navigation and routing in the original React version.
- **Redux Toolkit** – Managing global application state, including shopping cart functionality.
- **TanStack React Query** – Handling asynchronous requests, data fetching, caching, and server-state synchronization.

### Backend
- **Node.js** – JavaScript runtime environment for server-side development.
- **Express.js** – Backend framework for building REST APIs and handling application routes.
- **MongoDB** – NoSQL database for storing and managing application data.

### Payment Integration
- **Stripe** – Payment gateway integration for processing online payments.

### Authentication (In Progress)
- **Auth.js (NextAuth.js)** – Implementation of user authentication and session management.

## ✨ Features

- Browse and explore available products.
- View detailed product information.
- Add and manage products in the shopping cart.
- Global state management using Redux Toolkit.
- Application navigation and routing.
- Frontend and backend integration through API requests.
- Data storage and management using MongoDB.
- Asynchronous data fetching and caching with TanStack React Query.
- Stripe payment gateway integration.

## 🔄 Current Development

The project is actively being improved and migrated to Next.js.

Current development goals include:

- Migrating the existing React application to Next.js.
- Improving the user interface and overall user experience (UI/UX).
- Implementing Auth.js for secure user authentication and session management.

- Preparing the application for production deployment and online hosting.

## 🏗️ Architecture

The original application follows a Full Stack architecture:

- **Frontend:** React.js, responsible for the user interface and interactions.
- **Backend:** Node.js and Express.js, responsible for business logic and API endpoints.
- **Database:** MongoDB, responsible for persistent data storage.
- **Payment Gateway:** Stripe, used to demonstrate online payment processing.

The architecture is currently being adapted to Next.js as part of the ongoing modernization process.

## 🎯 Project Goals

The main objective is to build a modern, scalable, and fully functional e-commerce platform while gaining practical experience with Full Stack development, payment integrations, authentication systems, database management, and modern web technologies.

The final goal is to deploy the application online and make it available as a real-world e-commerce project.
